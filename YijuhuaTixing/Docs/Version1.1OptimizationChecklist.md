# 一句话提醒 1.1 优化清单

日期：2026-06-12
定稿更新：2026-06-24

目标：在不影响 `1.0` 提审资料的前提下，提前准备 `1.1` 的本地优化任务。优先处理发审风险和已上线后用户会直接遇到的边界状态，暂不扩展地图类大功能。

## 工作原则

- 仅在本地或 `1.1` 分支推进，不修改已提交的 `1.0` App Store Connect 审核资料。
- 不把年度会员 Product ID 改回 `com.yijuhua.pro.yearly`，继续使用 `com.yijuhua.pro.annual`。
- `1.1` 先解决账号、会员、解析和官网备案预留；地图 SDK 放到 `1.2` 或后续版本单独评估。
- 中国大陆地区开放依赖 ICP 备案完成，备案号未取得前不填假号、不开放中国大陆销售范围。

## 优先级总览

| 优先级 | 模块 | 目标 | 状态 |
| --- | --- | --- | --- |
| P0 | 个人信息 / MockAuthService | 降低发审风险 | 已定稿：隐藏入口 |
| P0 | 会员中心体验 | 补齐购买和订阅边界状态 | 待开发 |
| P1 | 提醒识别优化 | 提升核心体验和测试覆盖 | 待开发 |
| P1 | 官网备案号预留 | 备案完成后可快速上线备案号 | 待开发 |
| P2 | 中国大陆上架准备 | 准备 ICP 后的地区、截图和价格资料 | 待准备 |

## P0：个人信息 / MockAuthService

发审风险最高。`1.1` 已选择路线 A：隐藏个人中心入口。

- 路线 A：隐藏个人中心入口。
  - 隐藏设置页中的个人信息入口。
  - 保留本地提醒、会员中心、协议链接等不依赖账号的功能。
  - 清理或隔离 `MockAuthService` 在正式构建中的可见路径。
  - 适合先快速降低审核风险。
- 路线 B：接入真实可用账号体系。
  - 按 `AccountSpec.md` 接入手机号验证码登录。
  - 提供退出登录、账号注销、个人信息读取和修改。
  - 完成隐私问卷口径更新。
  - 适合需要会员、设备或后端数据长期统一时再做。

验收标准：

- 正式构建中不出现不可用的模拟登录或模拟个人资料。
- 审核员无需登录也能测试核心提醒功能。
- 若保留账号入口，登录、退出、注销和错误提示必须完整可用。

## P0：会员中心体验

围绕 StoreKit 商品加载、购买、恢复购买和订阅刷新补齐状态。

待办：

- 商品加载中显示明确状态，不展示硬编码人民币兜底价。
- 商品加载失败显示可恢复提示，例如 `会员信息加载失败，请稍后再试`。
- 购买取消使用轻提示，不展示错误弹窗。
- 购买失败展示可理解原因，并保留重试入口。
- 恢复购买入口可用，成功后刷新会员状态。
- 进入会员页、购买成功、恢复购买成功后都刷新当前 entitlement。
- 无有效订阅时清晰显示免费状态；有效订阅时显示套餐和到期时间。

验收标准：

- StoreKit 商品加载成功时展示当地价格。
- StoreKit 商品加载失败时不显示错误价格。
- 恢复购买、购买失败、购买取消都有对应 UI 反馈。
- `SubscriptionServiceTests` 覆盖主要边界分支。

## P1：提醒识别优化

继续打磨一句话解析，优先补齐用户高频表达。

待办：

- 支持 `本周几`、`下周几` 的日期识别。
- 支持 `每周`、`每月` 重复提醒表达。
- 对缺少具体时间的表达给出确认提示，而不是静默猜测。
- 补齐模糊时间表达，例如 `上午`、`下午`、`晚上` 的默认时间策略。
- 将新语料加入 `yijuhua-tixing-nlp-test-corpus-v0.1.jsonl`。
- 更新 `parser-rules.md`，保持规则和测试语料一致。

验收标准：

- 新增解析场景都有单元测试。
- 解析失败或信息不完整时，确认页能让用户明确补时间。
- 不回归今天、明天、具体日期、具体时间等基础解析。

## P1：官网备案号预留

ICP 备案完成前只准备代码位置，不填假号。

待办：

- 官网页脚预留备案号展示组件或配置字段。
- 备案号为空时不显示备案文本。
- 备案号配置后可在页脚显示并链接到工信部备案网站。
- 更新官网部署文档，标注备案号配置位置。

验收标准：

- 无备案号时线上页面不出现占位假数据。
- 有备案号配置时页脚展示符合常见备案格式。

## P2：中国大陆上架准备

备案通过后再执行，不作为 `1.1` 发版前置阻塞。

待办：

- 准备人民币价格版本会员截图。

- 复测 `https://yijuhuatixing.cn/support`、`/privacy`、`/terms` 在中国大陆网络可访问。

验收标准：

- 中国大陆地区截图、价格和 URL 与实际上架状态一致。
